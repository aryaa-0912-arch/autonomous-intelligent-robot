# Autonomous Intelligent Robot

A long-term Robotics & Automation project focused on developing a small-scale autonomous mobile robot capable of intelligent navigation, obstacle avoidance, mapping, localization, and autonomous decision-making.

## Project Goal

The robot is designed to:

- Navigate autonomously from one point to another
- Build and use maps of its environment
- Estimate its own position
- Detect obstacles
- Plan and re-plan paths
- Avoid obstacles dynamically
- Eventually use computer vision for object detection
- Demonstrate autonomous decision-making

## Technology Stack

- Path Planning

## Current Stage

Currently developing the robot model and simulation environment using ROS 2 and Gazebo.

### Hardware Plan

The future physical prototype is planned to use:

- 4-wheel differential-drive chassis
- DC geared motors with encoders
- Microcontroller
- IMU
- Ultrasonic sensors
- Camera
- LiDAR (future upgrade)

## Development Roadmap

1. ROS 2 and Linux fundamentals
2. Robot modeling with URDF
3. Gazebo simulation
4. Differential-drive motion
5. Wheel encoder odometry
6. Sensor integration
7. Obstacle avoidance
8. Mapping and localization
9. Autonomous navigation
10. Computer vision
11. Dynamic obstacle avoidance
12. Physical robot prototype
13. Testing and performance evaluation

## Project Status

🚧 **Under Development**

This project is being developed incrementally, from simulation to a physical autonomous robot.
